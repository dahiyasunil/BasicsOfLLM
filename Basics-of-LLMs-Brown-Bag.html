LLM basics

What is an LLM?

An LLM is a very powerful autocomplete.

It is a function of text that outputs a probability distribution of the next token.

f(text) → p(next token)
text so far (input) probability of every possible next token (output)

A token is a piece of text, roughly a word. More on that in a few slides.

What are parameters?

The numbers inside the model.

When you hear “a 70B model”, that is 70 billion of them. Training sets their values.

One step

Guess the next token, compare with the real one, then nudge every number a little.

Repeat

Trillions of times, starting from random numbers. The result is a good set of values, not a perfect one.

Tuning the numbers

Training is like tuning an old radio.

Each knob is one parameter. You are hunting for the settings where the station comes in clear.

Try

Turn one knob a little. Clearer? Keep it. Worse? Turn it back.

Repeat

Every knob, many tiny turns. The static fades. Not perfect, just good enough.

Scale up

Same idea, 70 billion knobs. Training does the turning, automatically.

What is a token?

A token is the smallest unit processed by an LLM.

Tokens are subword chunks produced by a tokenizer, rather than complete words or individual characters.

What is a context window?

The most tokens a model can handle in one request.

Your input and the model's reply share it.

Most models: roughly 200K to 1M tokens, some larger. 1M tokens ≈ 750K words ≈ 1,500 to 3,000 pages. It varies by model and changes often, so check yours.

LLM basics

Quick questionContext rot

Your window fits 10 documents. Only 2 are relevant to the question.

Send all 10, or just the 2?

Send just the 2. It fits, but that doesn't mean it works well.

Quality

More noise for the model to sort through.

Cost

Input tokens are typically billed on every request.

Speed

More tokens take longer to process.

The more tokens in the context, the less reliably the model uses any of them. Even when everything fits.

  • Facts that are in the context get missed
  • Answers get less accurate
  • Long chats drift off course

Chroma Research, 2025: 18 models tested, and all got less reliable as input grew. Even one distractor lowered accuracy. A focused ~300-token prompt beat the full ~113K-token version on a memory test.

LLM basics

Use the window wisely

Don't aim to fill it.

Quality fades gradually, so aim for the smallest set of high-signal tokens that gets the job done.

Rule of thumb

Start wrapping up around 40 to 70% full. No official number: it varies by model and task.

Hand off

Ask for a note: goal, decisions, current state, next steps, key files.

Continue

Paste it into a new chat and carry on.

Also

One chat per topic. Send only relevant files. Drop stale tool output.

What is an embedding?

A vector that stands for the meaning of text.

A vector is a list of numbers. Similar meaning gives nearby vectors. And directions between vectors carry meaning too.

Your turn

King and queen are shown, and so is man. Where would woman land? Point to a number.

Hint

Take the king → queen arrow and start it from man.

Answer

Number 4. Woman lands at the arrow's tip. The model never labelled that direction, it learned it from text.

Takeaway

No single number means anything. Meaning is in the whole vector, and in distances and directions.

Token ID

The tokenizer gives each token one ID number. That is only a label. The embedding turns it into a vector.

How do we tell if two vectors are close?

Text match?

Should we just match the words? The question and the paragraph share no words, so nothing is found, yet the paragraph answers it.

Vectors

Turn both into vectors. Texts with similar meaning give similar vectors.

Cosine similarity

A score that compares the direction of two vectors. near 1 · matchingnear 0 · not matching

How an LLM is trained · 1 of 2

Pre-training

Guess the next token, trillions of times.

The data

A large share of the public internet, plus books and code.

The loop

Show the start of a text, hide the next token, compare, nudge. The same loop as the parameters slide.

The cost

Thousands of GPUs, running for months.

Question

The result is a base model: it knows the language and a lot of facts. What will it reply to a question?

Answer

It continues the pattern. It was trained to continue text, not to answer questions.

How an LLM is trained · 2 of 2

Post-training

From text continuer to assistant.

Step 1

Show it thousands of questions with ideal answers. It learns: a question gets an answer. (Supervised fine-tuning.)

Question

What problem could this create?

Problem

Hallucination: it answers confidently even when it doesn’t know. Like filling the exam sheet instead of leaving it blank.

Step 2

Show two answers, say which one humans prefer. Repeat millions of times. (Reinforcement learning from human feedback.)

Question

What’s the issue with this step?

Problem

Human bias: people like confident, flattering, longer answers, so models learn to tell us what we want to hear.

Every organization does its own post-training, so models get different personalities. Pre-training gives knowledge. Post-training gives behaviour.
